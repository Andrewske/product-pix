# Universal Angles & Shot Types

Core shots that work across Amazon, Etsy, eBay, Shopify (Soona, TrulyFinePixels, ProPhotoStudio):

1. **Hero/Main (studio)**: Straight-on, pure white/neutral background, 85-90% frame fill, square crop, no text/graphics.

2. **Orthographic angles**: Front/back/side/top views. Required for apparel, electronics, furniture.

3. **3/4 or 45° angle**: Adds depth/form. Amazon shoe standard (45° left-facing).

4. **Detail/Macro**: Close-ups of texture/material/ports/controls. Shows quality, reduces returns.

5. **Scale shot**: In hand/with reference object/dimension overlay. Prevents size mismatch returns (~22%).

6. **Lifestyle/In-use**: Product in natural context. Builds ownership aspiration (home/apparel/tools/food/beauty).

7. **Group/Variant**: Multiple colors/sizes/sets together.

8. **Packaging/In-the-box**: Box contents layout. Builds trust, shows included items.

9. **Information/Infographic**: Feature/dimension overlays. Amazon/Shopify secondary only (eBay cautious).

10. **Process/Assembly**: Step-by-step for DIY/setup products.

11. **Condition/Defect**: Wear/scratches/patina close-ups. Essential for used/vintage items.

Universal set covers 90% of marketplace requirements.

# Recommended Minimum Shot Counts

## Platform Requirements
- **Amazon**: 1 required, up to 9 allowed. ≥6 recommended + video (Soona). ≥1000-1600px for zoom.
- **Etsy**: Cover 7 types (studio/lifestyle/scale/detail/group/packaging/process).
- **eBay**: Up to 24; 3-12 practical range, more for complex items.
- **Stats**: 78% want more images (BigCommerce), 76.5% cite quality as decisive (ProductCapture), ~22% returns from visual mismatch.

## Category Minimums (Conversion-Oriented)
- **Simple products** (accessories/CPG/tools): 6 images - hero/3-4 angle/back-side/detail/scale/lifestyle-packaging
- **Apparel/Footwear**: 8-10 images - 3-4 on-body angles, 1-2 flat-lay, 2 details, scale + lifestyle
- **Electronics/Gadgets**: 8-10 images - 3-4 angles, 2-3 details, in-box, lifestyle/scale
- **Furniture/Home**: 8-12 images - 3-4 angles, 2-3 material details, 2 room shots, 1-2 infographics
- **Beauty/Food**: 6-8 images - front/angle/back, texture/inside, lifestyle, packaging

Maximize slots: Amazon (7-9), Etsy (10), eBay (24) for better CTR/conversion.

# Key Findings

1. **Platform Compliance Critical**: Amazon (pure white main, ≥85% frame, no text/props), eBay (no text/graphics), Etsy/Shopify (flexible but clean heroes preferred).

2. **High-Res + Zoom Boosts Conversion**: ≥1600×1600px recommended. Shoot high, downscale never up-res.

3. **Angle Variety Reduces Returns**: All sides + scale + texture/quality coverage minimizes "item not as described" claims.

4. **Standardize Category Sets**: Shot lists per vertical enable consistent production and brand recognition.

5. **Lifestyle Supports Info Shots**: Captures attention/emotion but users evaluate with detail-rich studio shots. Hero = clean studio, lifestyle secondary.

6. **Infographics**: Powerful on Amazon/Shopify (dimensions/benefits/icons), risky on eBay (search penalties).

7. **Used/Vintage**: Require explicit condition angles (flaws/labels/patina) to reduce disputes/returns.

8. **Conflicts**: Backgrounds (Amazon white-only), stock images (eBay new-only, Etsy prefers actual), text overlays (Amazon/Shopify OK secondary, eBay discouraged).

9. **Video/360**: Marginal gains in visual categories. Amazon requires video, short spins/demos lift engagement.

# File Naming Conventions

Pattern: `[SKU]_[SEQ]_[ANGLE]_[CONTEXT]_[VARIANT].jpg`

- **SKU**: Internal ID (ABC123)
- **SEQ**: 2-digit gallery order (01, 02, ...)
- **ANGLE**: Standardized codes
- **CONTEXT**: Optional (STUDIO, LIFE, INFO, INBOX)
- **VARIANT**: Optional (RED, BLUE, L, US)

## Angle Codes
- FR/BK: front/back
- SDL/SDR: side left/right  
- 34L/34R: 3/4 left/right
- TOP/BTM: top/bottom
- DTL: detail/macro
- SCL: scale (in hand/reference)
- PKG: packaging/box
- INB: in-the-box layout
- LIF: lifestyle/in-use
- INF: infographic overlays
- FIT: fit on body
- SWC: swatch/texture
- CON: condition/defect
- DIM: dimension diagram

Example: `ABC123_01_FR_STUDIO_MAIN.jpg`

SEQ controls gallery order and main image selection.

# Operationalization

## For Engineers/Data Analysts

1. **Reference Table**: CSV/schema with category, seq, angle, context, required, description fields

2. **Tooling Enforcement**: 
   - Validate uploads: minimum angles per category + filename regex
   - SEQ for auto-gallery ordering on Shopify/PIM

3. **Channel Tweaks**:
   - **Amazon**: 01_ must be pure white, no text/props; INF_ secondary only
   - **Etsy**: Emphasize LIF/PROC shots; keep FR_STUDIO clarity
   - **eBay**: Minimize INF_ (search penalties); require CON_ for used items

## eBay Adaptations (2024-2025)
- **Rules**: ≥500×500px (1600×1600 recommended), up to 24 photos, clean thumbnail, multiple angles + defects/wear close-ups
- **Avoid**: Text/borders/logos/watermarks, stock photos for used items
- **Emphasis**: Extra DTL_/CON_ shots (10-15 for used/vintage)
- **Extended Codes**: CON_DMG (damage), CON_WR (wear), CON_TAG (authenticity)
- **Base List**: FR/34L/BK/SDL/DTL feature/label/SCL/LIF + CON_* when condition ≠ new
- **Validator Rule**: eBay + used → require ≥2 *_CON_* files

---

## Poshmark Adaptations
**Platform Notes**: Mostly fashion/shoes/accessories/home decor. Historically 1:1 square, tested portrait (3:4/4:5) in 2025, rolled back to square. Minimal communication = expect churn.

**Defensive Strategy**: Shoot with crop room, auto-generate 1:1 master + optional portrait.

**Cover Photo**: Thumbnail for feeds/search - full item (no cutoff), clean/uncluttered, Posh auto-whitens backgrounds.

**Apparel Shot List** (8-10 images): Emphasizes "real closet" + condition
1. `01_FR_FIT_MAIN` - Full front on-body/hanger (1:1 crop-safe)
2. `02_BK_FIT` - Back
3. `03_SDL_FIT` - Side/shape
4. `04_FR_STUDIO_FLAT` - Flat-lay for cross-listing
5. `05_DTL_STUDIO_FABRIC` - Fabric detail
6. `06_DTL_STUDIO_LABEL` - Brand/size/fabric tag (critical)
7. `07_CON_DTL_FLAW1` - Any flaw
8. `08_CON_DTL_FLAW2` - Second flaw/wear close-up
9. `09_LIF_MIRRORSELFIE` - Real try-on shot
10. `10_SCL_FIT_FULLBODY` - Full-body fit

**Footwear**: 01_34L main pair, 02_TOP, 03_BK, 04_BTM (soles essential), 05_DTL_LOGO, 06-07_CON_TOE/HEEL, 08_LIF_ONFOOT

**Condition Alignment**: Granular fields like eBay. If condition ≠ "New with Tags" → require ≥2 CON_ images (CON_WR_OVERALL + CON_DMG_[AREA])

# Channel-Specific Rules Summary

**eBay**:
- Min dimensions: longest_side ≥ 800px (supports zoom)
- Text handling: Block/flag INF_ files (search penalty risk)
- Used items: condition ≠ 'new' → require ≥1 *_CON_WR_* + ≥1 *_CON_DMG_* (if flaws exist)

**Poshmark**:
- Aspect safety: 01_ image must have safe 1:1 crop (no cutoff)
- Apparel/footwear: Require label shot (*_DTL_*LABEL* or *_DTL_*TAG*)
- Condition: ≠ "New with Tags" → require ≥1 *_CON_* image
