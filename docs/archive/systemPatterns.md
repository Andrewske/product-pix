# System Patterns

## Architecture
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript (Strict)
- **Styling**: Tailwind CSS v4, shadcn-ui
- **State/Data**: Supabase, React Server Components

## Coding Standards (from AGENTS.md)
- **FP First**: Pure functions, immutability.
- **Naming**: kebab-case (files), camelCase (functions), PascalCase (types).
- **Testing**: Bun test.
- **Validation**: Zod.
- **Error Handling**: Result type pattern.

## UI/UX Patterns
- **Colors**: Deep Black (Background), Electric Coral (Accent/CTA), Cream (Text), Mint (Success).
- **Typography**: Inter (or Satoshi/General Sans).
- **Shapes**: Sharp corners or subtle radius.
