# Project Brief: ProductPix

## Overview
ProductPix is an AI-powered product photo generator designed to help users generate professional product photos.

## Core Goals
- Provide high-quality AI image generation for product photography.
- Simplify the workflow for e-commerce businesses.
- Maintain a high standard of code quality (FP, strict types).

## Current Phase
- Redesigning the UI/UX with a "Dark + Warm" aesthetic using shadcn-ui and Tailwind v4.
